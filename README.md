# H YOGA · 배움을 잇는 공간

가상 데이터로 살펴보는 요가 교육·운영 프로토타입입니다. 이 저장소에는 정적 배포 파일만 포함합니다.

웹사이트: https://ryusimyeong.github.io/h-yoga-demo/

수강생 코드 `H38-SU02`로 시작하거나 상단의 데모 역할을 변경할 수 있습니다. 교재·학습 기록·출석·모임·문제은행·예시 PDF를 시연합니다.

실제 인증·서버 저장·기기 간 동기화·결제·알림·공식 이수 인증은 제공하지 않습니다. 데이터는 방문자별 브라우저에 따로 저장됩니다. 검색 제외 메타는 접근 보호가 아닙니다.

폰트 출처와 라이선스는 `fonts/SOURCE.txt`, `fonts/OFL.txt`에 있습니다. 원본 기획서와 인터뷰 문서는 포함하지 않습니다.
